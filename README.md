# Clarity Architect Skill

This package contains a reusable ChatGPT Skill definition for turning unclear thoughts, notes, text fragments, and workflows into structured, actionable, handoff-ready output.

## Files

- `SKILL.md` — main skill instructions

## Suggested Use

Install or copy the contents of `SKILL.md` into your skill-building environment.

The skill is especially useful for:

- structuring chaotic notes
- refining drafts
- creating agent handoffs
- making decision briefs
- generating status matrices
- identifying assumptions, risks, and next steps
